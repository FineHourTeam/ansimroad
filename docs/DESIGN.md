# 안심로드 디자인 브리프 (v1 · 2026-10-04)

> 사용자 요청 "로고부터 UI/UX 개선해 봐"(2026-10-04)에 따라 정한 방향. 토큰 값은 `src/styles/tokens.css`가 소유한다.

## 한 줄 방향

**목포 바다 여행 수첩.** 청록 바다와 해 질 녘 모래빛을 바탕으로, 여행 수첩처럼 정돈되고 다정한 화면. 밝은 · 여행 기분의 · 다정한.
기본 컴포넌트 키트 그대로의 인상(회색 테두리 상자만 쌓인 화면)에서 벗어나는 것이 목표다.

## 색 (토큰만 쓴다 — hex 금지)

| 역할 | 토큰 | 쓰는 곳 |
|---|---|---|
| 바다 청록 (브랜드) | `primary` | 주 행동 버튼, 선택된 칩, 번호 배지, 지도 선 |
| 청록 옅은 바탕 | `primary/10`, `primary/5` | 히어로 띠, 선택 영역, 안내 상자 |
| 모래 (따뜻한 강조) | `highlight` / `highlight-foreground` (#F7C548 / #583408) | '운영진 추천' · '지금' 이외의 강조 배지(`Badge variant="highlight"`), 로고 해, 별점 |
| 따뜻한 바탕 | `background-subtle` (#F8F4EC) | 화면 아래 깔리는 면 (카드는 흰색으로 띄운다). `PageBody`가 깔아 준다 |
| 지금 선 | `now-line` | 일정 위 빨간 '지금' 선만 |
| 응급 | `emergency` · `emergency-soft` | 응급실 · 약국만 |

- 한 화면에 강조색은 청록 + 모래 두 가지까지. 빨강은 '지금'과 응급에만.
- 글자 대비 4.5:1 이상 (어르신 화면은 회색 글자 금지).

## 글자

- Pretendard 하나. 제목은 `font-extrabold tracking-tight`, 본문 `text-base` 이상(자녀 화면), 어르신 화면 `text-xl` 이상.
- 크기 단계: 화면 제목 `text-2xl` · 구역 제목 `text-lg font-bold` · 본문 `text-base` · 보조 `text-sm`. 한 화면에 네 단계까지.
- 숫자(시각 · 분)는 `tabular-nums`.

## 모양

- 카드: 흰 바탕 `bg-card` + `rounded-2xl`(16px) + 옅은 테두리 + `shadow-sm`. 카드 안 여백 `p-5` — `Card` 기본값. 버튼 · 입력은 `rounded-lg`(12px), 큰 버튼(`xl` · `cta`)은 `rounded-xl`(16px).
- 화면 바탕은 `bg-background-subtle`(따뜻한 면) 위에 카드를 띄우는 구성을 기본으로 한다. 단, 첫 화면 히어로와 어르신 화면은 예외.
- 칩: 둥근 알약(`rounded-full`), 고른 칩은 청록으로 채운다 (`ToggleGroup variant="choice"`).
- 주 행동은 화면 아래 고정 띠(`sticky bottom-0`, 위쪽 옅은 그림자 `shadow-bar`, 안전 영역 여백)에 둔다: 조건 입력의 '코스 만들기', 코스 상세의 '이 코스로 확정하기' — `StickyActionBar`.
- 아이콘은 `@/components/icons`만. 장식 일러스트 대신 사진 · 지도 · 번호 배지로 여행 기분을 낸다.

## 로고

- 심볼: 청록 지도 핀 안에 모래빛 해가 떠 있고, 아래로 흰 물결 길이 지나간다 (목포 바다 · 길 · 안심). 두툼한 둥근 선, 16px에서도 형태가 읽힌다.
- 글자 로고: '안심로드' Pretendard ExtraBold, 청록, 자간 -3%. 윤곽선(path)으로 굳혀 `<img>`에서도 같은 모양.
- 앱 아이콘: 청록 둥근 사각형 위 흰 핀(해 모래빛 · 물결 청록). 브라우저 탭 파비콘은 사각형 없이 심볼만.
- 청록 바탕 · 사진 위 · 다크 모드에서는 흰 핀 판(`tone="white"`, 다크 모드는 저절로).
- 원본은 `web-assets/logo-source/build.py`(심볼 · 글자 로고 → `public/brand/*.svg` · 앱 아이콘 `logo-source/logo.svg`), 파비콘 · 앱 아이콘 · OG는 `node web-assets/generate.mjs`로 다시 만든다.
- 앱 안에서는 `BrandMark`(심볼) · `BrandLogo`(심볼 + 글자) 컴포넌트로만 쓴다.

## 화면별 원칙

- **첫 화면**: 청록 히어로(로고 · 한 줄 소개 · 세 단계 · 확인한 장소 수) → 질문 카드 6개 → 아래 고정 '코스 만들기'.
- **코스 제안 · 상세**: 사진이 먼저, 그다음 코스 이름 · 동선 · 시간. 안전 정보(응급실)는 경보처럼 보이지 않게.
- **자녀 화면**: 맨 위에 '지금 어디쯤' 상태 카드, 그다음 지도 · 일정. 보조 기능(코스 수정 · 링크 · 인쇄)은 한 줄 메뉴로 묶는다.
- **어르신 화면**: 일정이 화면의 주인공. 아래 고정 띠는 화면 높이의 1/4을 넘지 않는다 (사진 남기기 한 줄 + 응급실 한 줄).
- **리포트**: 사진이 주인공인 여행 앨범. 공유 버튼은 위아래 두 번.
- **인쇄용**: A4 여백 12mm, 위 머리띠(로고 · 날짜 · 코스 이름), 시간 줄, 장소 정보는 작은 꼬리표, 아래 QR 두 개. 한 장에 들어간다.
- **이미지로 저장 · 공유**: 인쇄용과 같은 내용을 휴대폰 화면 비율 카드(가로 1080px)로. 외부 사진(관광공사)은 담지 않는다.
- **운영진**: PC 기준, 왼쪽 목록 · 오른쪽 편집. 저장 띠는 아래 고정.
